# Онбординг нового магазина (To-Be) - описание точки верификации

## Что меняется

Ручной перенос номенклатуры заменяется автоматическим конвейером. ИТ-инженер снимает дамп товаров со старой кассы и загружает его в Data Integration Portal (вместо отправки Excel файла почтой). Портал валидирует и нормализует файл и передаёт его в AI Mapping Service, который сопоставляет позиции купленной сети с эталонной мастер-базой SKU в SAP ERP. Товаровед больше не размечает весь ассортимент вручную — он работает только со спорными позициями.

## Как происходит маппинг

Для каждой строки исходного файла AI-сервис делает две вещи:

1. Точное сопоставление по штрихкоду. Если штрихкод из дампа однозначно совпадает со штрихкодом эталонной базы — позиция связывается напрямую.
2. Семантическое сопоставление по названию для позиций без штрихкода или с расхождениями (например, «Шамп. Head&Shoulders 400» → «Шампунь H&S 400мл Основной уход»). Сервис оценивает близость к кандидатам эталонной базы и возвращает confidence-score по каждой позиции.

## Точка верификации

Маршрутизация идёт по порогу уверенности:

- **confidence ≥ 95%** — позиция сопоставляется автоматически, без участия человека.
- **confidence < 95%** — позиция попадает в UI-очередь товароведа, где он подтверждает предложенный вариант или выбирает правильный из списка кандидатов. Проверяется только эта небольшая доля ассортимента, а не 80% позиций, как раньше.

## Снижение ошибок и контроль качества

Перед загрузкой в SAP ERP срабатывает автоматический контроль качества, который проверяет возможные ошибки в данных:

- проверка на дубли штрихкодов (один штрихкод не может указывать на два SKU);
- проверка аномалий цен и маржи — резкое расхождение цены источника и эталона (защита от привязки дешёвого товара к дорогому штрихкоду и продажи в минус);
- выборочный QA-аудит авто-подтверждённых позиций (у которых confidence ≥ 95%) для контроля точности модели.

Товаровед исправляет позиции, в которых найдены ошибки.  
Только прошедшая эти проверки номенклатура загружается в SAP ERP, публикуется как каталог и прайс-лист и активируется на кассе. После этого магазин готов к открытию.
